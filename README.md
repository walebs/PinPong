A Norwegian web app developed by Wale Belal Sayed that helps people find table tennis tables nearby Oslo, Lørenskog and Lillestrøm.

Features
-Find table tennis tables on a map
-See indoor and outdoor locations
-Filter by lighting, cover, and other features
-View photos and directions
-Save favorite tables
-Submit new tables
-Report incorrect information
-Goal

The goal of PinPong.no is simple: make it easy to find a nearby table and start playing as quickly as possible.

PinPong.no is designed with privacy in mind and does not use cookies or tracking tools.
